# UX46: Flag-moment button on the recording HUD

Band origin: filed 2026-07-29 (owner exploratory sweep, item 16: surface features that exist but are invisible; the flag hotkey ranked high because its surface is on screen whenever the feature is usable). Status and priority live in this task's ToC row in [meetingpipe-q6-backlog.md](../meetingpipe-q6-backlog.md).

## Context

FEAT8's moment flag (a hotkey stamps a timestamp marker with a quiet HUD blink; markers land in a sidecar, anchor into the transcript, and get their own summary block) is entry-invisible: the only trigger is the global hotkey (`Coordinator.swift:480-487` to `MeetingSessionController.swift:216`), and the only in-app mention is the Preferences General hotkey row's sublabel (`PreferencesView+General.swift:69-71`). The HUD, present for the entire window in which flagging is possible, offers Stop and the off-the-record toggle (`RecordingHUDWindow.swift:356`, :365, right-click menu :528-544) but no flag.

Downstream is already built and good: flag chips render inline in the transcript (`TranscriptTab.swift:46`, :696-710) and the summary carries a flagged-moments block (`markers.py:21-26`). The gap is purely that a user who has not read the hotkey list will never create one.

## Scope

- A flag button on the HUD control row beside the off-record toggle (`HUDOffRecordButton`'s sibling shape, `RecordingHUDWindow.swift:749-757` is the pattern): SF Symbol flag, `.help` tooltip, VoiceOver label, firing the same `MeetingSessionController` entry the hotkey uses (one path; the button must not grow its own marker writer).
- The existing quiet blink acknowledges the press (the hotkey already triggers it; the button reuses it).
- A "Flag this moment" item in the HUD's right-click menu beside the off-record item (:528-544), for parity.
- Width coordination with UX35 (filed the same day): UX35 converges the pill on one width for the recording and off-record states; a third control changes the arithmetic, so whichever task lands second sizes for the final control count. Recorded in both specs.

## Explicitly not in scope

Any change to marker storage, the sidecar, or the summary block (FEAT8's, shipped). A markers list UI beyond the existing transcript chips. Prompt-panel or menu-bar flag entries (the HUD is where the recording is; keep the surface singular).

## Acceptance

A test pins that the button and the menu item invoke the same session entry point as the hotkey (via `FakeSessionHost` or the controller seam), and that pressing while not recording is a no-op (matching the hotkey's guard).

`cd daemon && swift build` and `swift test` green (baseline at filing: 1770). Repo dash guard green.

Owner eyeball: during a recording, click the flag; the HUD blinks; after the pipeline runs, the transcript shows the chip at that timestamp and the summary carries the flagged-moments block. VoiceOver reads the button meaningfully.

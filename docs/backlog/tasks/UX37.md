# UX37: Ask is safe to leave (root-owned model, cancellable run, preserved state)

Band origin: filed 2026-07-29 (owner exploratory sweep, item 6: "Ask should be safe to leave. Currently if I ask anything, and then leave tab and get back, process got interrupted"). Status and priority live in this task's ToC row in [meetingpipe-q6-backlog.md](../meetingpipe-q6-backlog.md).

## Context

What the owner experiences as "interrupted" is state loss, not process interruption, and the truth is worse than a cancel: the run keeps going, invisibly, and its answer is thrown away.

The run's entire state is `@State` on the view struct: `question`, `asking`, `answer`, `errorText` (`AskView.swift:15-18`). `LibraryRootView` mounts `AskView` inside an `if/else` scope chain (`LibraryWindow.swift:747-751`), so switching to Facts or People tears the view down and destroys that state. The `Task {}` started by `ask()` (:224-248) is unstructured, so it is NOT cancelled on teardown; it completes into destroyed state.

The subprocess chain is `LibraryWindowModel.askMeetings` (`LibraryWindow.swift:358-360`) to `MeetingLibraryService.askMeetings` (`Library/MeetingLibraryService.swift:458-482`) to `PipelineLauncher.ask` (`PipelineLauncher.swift:437-461`): `runMP(["ask", question, "--out", tmp], timeout: 10 * 60)`. `retainForCancel` is not passed, so `cancelActiveRun()` cannot reach it (the UX28 machinery exists and is unused here); an abandoned ask holds a pipeline process for up to 10 minutes with no surface and no stop. The `--out` JSON is deleted in a `defer` (:441-442), so the returning answer is lost with the view.

Two adjacent losses. The `meetingpipe://ask?q=` deeplink prefill is consumed and cleared before the run (`AskView.swift:46` clears `model.pendingAskQuestion`), so navigating away loses even the question. And nothing anywhere persists an answer or history; every visit starts blank.

The in-repo fix precedent is two scopes over: `DigestListModel` is an `ObservableObject` held as `@StateObject` by the Library root (`DigestsView.swift:14-26`, `LibraryWindow.swift:450`, `:760`), so a scope switch destroys only the view and an in-flight generate lands on surviving state (`DigestsView.swift:164-178`).

## Scope

- Introduce `AskModel: ObservableObject` (question, asking, answer, errorText, and a session-scoped list of past question/answer pairs) held as `@StateObject` on the Library root beside `digestList`; `AskView` becomes a renderer over it. An in-flight ask completes into the model whether or not the view exists.
- Thread `retainForCancel: true` through `PipelineLauncher.ask` and give the running state a visible Cancel (the UX28 idiom: the run is cancellable, the cancel surfaces as a named outcome, not a silent blank).
- Preserve the deeplink question until the run it started completes (consume-on-completion, not consume-on-render).
- Session history stays in memory (the model), newest first, so returning to Ask shows the previous answers this session. Durable on-disk history is UX38's call, not this task's.

## Explicitly not in scope

Engine performance, indexing, and memory behavior (AI11 owns that; this task makes the UI honest around whatever the engine costs). The Ask pane redesign (UX38, which depends on this model extraction). Durable cross-restart history. Parallel asks (one at a time stays; a second ask while one runs queues or replaces per the model's single `asking` slot, record which).

## Acceptance

Model-level tests: start an ask, simulate view teardown (drop the view, keep the model), deliver the completion; the answer is present when the view remounts. Cancel invokes the launcher's cancel path (fake launcher records `retainForCancel: true` and the cancel call). The deeplink question survives a mount-unmount-mount cycle until its run completes. History accumulates newest-first and caps sanely (pick a cap, record it).

`cd daemon && swift build` and `swift test` green (baseline at filing: 1770). Repo dash guard green.

Owner eyeball: ask a question, immediately switch to Facts, come back; the spinner is still there and the answer arrives in place. Cancel a slow ask; the pane says it was cancelled instead of going blank.

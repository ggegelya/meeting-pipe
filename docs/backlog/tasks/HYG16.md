## Context

Re-checked in code on 2026-10-25 against `01e904a`. Each item is small and independent; together they are the Python low-severity tail of the audit.

1. **A copied helper with a private import.** `prefetch_model._bytes_on_disk` and `storage.bytes_on_disk` have the same body line for line (`rglob("*")`, skip symlinks, swallow `OSError`). `doctor` reaches the private copy (`from .prefetch_model import _bytes_on_disk, hf_cache_dir`), and `tests/test_doctor.py` patches `"mp.prefetch_model._bytes_on_disk"` three times. [PIPE21](./PIPE21.md) lists that import among its five cross-module privates.
2. **Two log-reading helpers written twice.** `logs_cmd._parse_since` and `analyze_detection._parse_since` are identical (relative `Nh`/`Nm`/`Nd`/`Ns`, else ISO with naive read as UTC). `logs_cmd._iter_events` inlines the same skip-blank, skip-malformed JSONL loop that `analyze_detection.iter_events` already provides.
3. **Log paths frozen at import, ignoring `MEETINGPIPE_LOGS_DIR`.** `logs_cmd.LOGS_DIR`, `analyze_detection.DEFAULT_EVENTS_PATH` (also the argparse default) and `doctor._RECORDER_LOG` (also the default argument of `_scan_recorder_log_for_tcc`) are each `Path(os.path.expanduser("~/Library/Logs/MeetingPipe..."))` at module level. Both writers honour the variable (`events.logs_dir` on the Python side, `Log.resolveLogsDir` on the Swift side), so under a sandboxed run `mp logs`, `mp analyze-detection` and doctor's ScreenCaptureKit check read the user's real logs instead of the run's. [T9](./T9.md) owns the two writers that bypass `logs_dir` and names these three as read-only and out of its scope.
4. **Fourteen copied logging setups.** `logging.basicConfig(level=logging.INFO, ...)` appears in 14 subcommand `main`s: 10 with `"%(asctime)s %(levelname)s %(name)s: %(message)s"` (`diarize_cleanup`, `dogfood`, `finalize`, `prefetch_model`, `publish_from_paste`, `publish_cmd`, `publish_notion`, `summarize_local`, `summarize`, `train_adapter`) and 4 with the same format minus the timestamp (`ask`, `digest`, `merge_meetings`, `mcp_serve`). `orchestrate._configure_logging` is separate, adds the `pipeline.log` file handler, and no-ops when the root logger already has handlers, which is why the router cannot simply configure logging once before dispatch.
5. **The dispatch ladder.** `__main__._dispatch` routes 23 subcommands through 23 `if cmd == ...` / `if cmd in {...}` branches, mccabe 24, the highest in `src` (`ruff --select C901`). The ladder is what `CONVENTIONS.md`'s "Subcommand pattern" prescribes, and two tests parse its shape: `test_main_dispatch._dispatch_table` walks the `ast.If` branches and `test_entry_contract._dispatch_targets` collects each `from .<module> import main as run`. `failure_details.describe` is second at mccabe 22: a prologue that digs status, body and request id out of an `httpx.Response`, then one ordered `elif` chain whose order is the precedence.
6. **Dead symbols.** An AST reference count over `src`, `tests` and `scripts` finds six top-level names no production code reads: `visibility.is_visible` (tests only), `events.drop_test_residue` (one test; its docstring calls it "The call every log reader owes the user", `CONVENTIONS.md` calls it "the canonical one", and `analyze_detection.main` says it deliberately does not call it), `services.NotionPublisher` (an alias kept for "an external caller", which a single-user product does not have), `config.CLI_BACKENDS` (tests only, yet its comment and `ARCHITECTURE.md` say `effective_backend` classes CLI backends through it, when `effective_backend` forces every non-`local` backend under zero egress and never reads it), `services.TextClient`, and `egress_guard.disarm`.
7. **An unsafe spawn form.** `LocalSummaryClient._spawn` passes `preexec_fn=os.setsid if hasattr(os, "setsid") else None`. Python documents `preexec_fn` as not safe in the presence of threads and names `start_new_session=True` as the replacement, which does the same `setsid` in the child without running Python there.

Re-checked at filing: the logging setups are 14, not 13; the ladder has 23 branches (mccabe 24); the two `_l2_normalize`s are not a copy (`voiceprint`'s works on `list[float]` and keeps that module numpy-free, `embed_index`'s on an `ndarray`), so they are dropped here and `roster`'s import of the private one stays with PIPE21; of the six dead names, `TextClient` is wired up by [TYPE2](./TYPE2.md) and `disarm` is a documented test seam, so four are deleted.

## Scope

One sweep, one commit per item, behaviour unchanged except where stated.

1. Delete `prefetch_model._bytes_on_disk`; `prefetch_model` and `doctor` call `storage.bytes_on_disk`; repoint the test patches.
2. `events.parse_since(s)` and `events.iter_jsonl(path)` beside `log_generations`; `logs_cmd` and `analyze_detection` use both and lose their copies.
3. Resolve the three paths at call time from `events.logs_dir()`: `logs_cmd` reads `logs_dir() / name`, `analyze_detection`'s `--events` defaults to `None` and resolves inside `main`, `_scan_recorder_log_for_tcc(log_path: Path | None = None)`.
4. `entry.configure_logging()` with the timestamped format, called by the 14 `main`s in place of their `basicConfig`. The four short-form commands gain a timestamp on stderr, the only visible change, named in the commit. `orchestrate._configure_logging` is untouched (T9).
5. `_dispatch` becomes a lookup in a module-level `SUBCOMMANDS: dict[str, str]` (every accepted spelling to its module name) plus `importlib.import_module(f".{module}", __package__).main(rest)`, keeping the imports lazy and the `_dispatch(cmd, rest)` signature that `test_mcp_serve` and `test_summarize_backend` use. `test_main_dispatch` and `test_entry_contract` read the dict instead of walking the AST, and `CONVENTIONS.md`'s "Subcommand pattern" shows a table row, in the same commit. If [PIPE20](./PIPE20.md)'s `mp dev <tool>` router lands first, its table takes the same shape; whichever lands second adapts.
6. After [PIPE28](./PIPE28.md) has added its 404 and 403 branches, extract `describe`'s prologue into `_http_facts(error)` returning status, body, request id and provider, leaving the cause chain in one function in its current order.
7. Delete `is_visible`, `drop_test_residue`, `NotionPublisher` and `CLI_BACKENDS` with their tests; correct the `CLI_BACKENDS` comment's claim and `ARCHITECTURE.md`'s PROV1 line to what `effective_backend` does, and `CONVENTIONS.md`'s residue paragraph to say no `mp` reader filters today and `is_test_residue` is the reference the `scripts/` mirrors track. ADR 0007 is history and is not edited.
8. `start_new_session=True` in `_spawn`, and the `local_server` module docstring that quotes the old form. If [LOCAL21](./LOCAL21.md) has removed the spawn, this item lapses.

# Code-quality audit, 2026-10-25

Scope: code quality below the architecture level, in both trees. That means code smells (refactoring.guru catalogue), language-idiom violations in Swift and Python, the repo's own `CONVENTIONS.md` and `CLAUDE.md` rules checked against the code, and what the linters do and do not enforce. Excluded by design: everything the [2026-10-24 architecture review](./2026-10-24-architecture-review.md) filed (god objects, config and backend primitive obsession, god modules, oversized views, comment rot, source-text tests, the file contract on the Swift side, raw `Process()` sprawl, and the rest of its band), and error handling and observability, which a parallel audit covers.

Method: four read-only finder angles in parallel (Swift daemon, Python pipeline, tests as code, conventions compliance and lint coverage), each told to measure rather than estimate and to dedupe against the active ToC and `owner-verification.md`. One raw finding was rated high (TS1); an independent skeptic told to refute it downgraded it to medium, confirming the numbers but not the impact, and corrected one count in TS2 (14 files without cleanup, not 9). Four mediums that claimed a behaviour defect were re-checked by hand in code (SW1, SW7, PY7, CV6) and held. No critical findings. Raw: 47 findings (SW 13, PY 15, TS 10, CV 9); after merging duplicates across angles and folding the lows, 20 proposed tasks.

## Summary

**Verdict: the code is in better shape than its size suggests, and the linters are set to see almost none of it.** There are no `try!` or `as!` in production Swift, all 21 `fatalError`s are `required init?(coder:)` boilerplate, observers are balanced (8 adds, 8 removes), the escape hatches that remain are lock-guarded, Python has no mutable defaults, no shadowed builtins, no bare `except:` and 741 of 742 functions annotated. The real cost sits in three places:

1. **Rules without a fence, and fences weaker than their rule.** Ruff selects four families (`E4 E7 E9 F`) while 34 `noqa` comments name rules nothing enables, `line-length = 100` is set and 192 lines break it, and `scripts/` is never linted (it holds a live F401). Swift has no linter or formatter at all. The design-token fence's `\b` alternatives never match under Apple Git, so the owner's local `ci-local.sh` is weaker than CI's. "Never `NSError(domain:)`" has 12 live sites outside A7's 16. The atomic-write rule has 10 hand-rolled copies and several non-atomic rewrites of the only copy of a file.
2. **Small duplicated templates that have already diverged.** The debounced-save template exists three times and one copy blocks the main thread on three `security` subprocesses per edit. ISO-8601 parsing is hand-rolled four ways, two of them with the strategy `LastBackup.swift` documents as failing on Python timestamps, and the stem formatter that names every recording lacks the `en_US_POSIX` locale its reader sets. `LocalSummaryClient` is assembled at six sites from different subsets of eleven parameters, which has already caused two bugs (LOCAL19, PIPE12). Thirteen JSON readers have three failure behaviours, and the unguarded ones crash every library-wide command on one list-shaped `meta.json`.
3. **Tests that depend on the machine they run on.** One Swift test leaves 230 MB in `$TMPDIR` per run (5.37 GB found), a pipeline test fails after a 60 s hang when the parent shell ignores SIGINT, two pipeline tests load the real MLX embedding model when it is installed, and Swift test doubles are copied up to seven times.

## What is fine and should stay

- Swift idiom hygiene in production: no `try!` or `as!`, every `fatalError` is NSView boilerplate, every remaining `@unchecked Sendable` really is lock-guarded, observers are balanced, Combine sinks capture weakly, `@ObservedObject` initialisers are singletons, `onAppear` work is cheap or detached.
- Python: annotation coverage (741 of 742), no mutable defaults, shadowed builtins, bare `except:`, `os.system` or `shell=True`, no naive-vs-aware datetime comparison, heavy imports lazy bar numpy.
- Python tests: tidy (longest 61 lines), no real network, no home-dir writes, a 45-line conftest. Swift skips are principled and allowlisted in `ci-local.sh`.
- The event-schema fence (281 of 282 Swift emits, 46 of 46 Python), subcommand registration parity, and the pre-commit em-dash hook (0 added in 76 commits since CI stopped checking).

## Could not see

- `swift test` and `swift build -c release` were not run; Swift test durations are literal-delay sums, not measurements.
- SW1's truncated stderr tail was not reproduced at runtime; the race and the missing drain are read from code and the complete-mode diagnostics.
- Whether `MeetingStore.parseRunTimestamp` fails on today's Python timestamps (ARCH17's spec checks this first).
- No Swift linter was installed or run, so no baseline exists for one; dead-code detection is single-token reference counting and can miss a reused name.
- T12's 36-test skip gap is inferred from two runs' counts, not observed with `-rs`.

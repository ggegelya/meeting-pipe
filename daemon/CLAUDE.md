# daemon/ — Swift menu-bar app

**This file holds constraints you must obey while editing Swift here, and nothing else** (DOC15's answer to what it is for, with the reasoning in [gotchas](docs/gotchas.md#what-belongs-in-an-always-loaded-file)). It is prepended to every prompt in this subtree, so anything looked up occasionally belongs elsewhere: subsystem map and file index in [`../ARCHITECTURE.md`](../ARCHITECTURE.md), patterns in [`../CONVENTIONS.md`](../CONVENTIONS.md), terms in [`../ARCHITECTURE.md#glossary`](../ARCHITECTURE.md#glossary), commands in the root [`../CLAUDE.md`](../CLAUDE.md) verify table.

Each rule is one line linking to [`docs/gotchas.md`](docs/gotchas.md) for the incident that produced it, most recording a measurement. **Read the linked section before you argue with a rule or decide your case is the exception.** A new rule is a line here plus a section there in the same commit, never a paragraph here (DOC14), and two rules on one subject merge rather than accrete (DOC15).

## Build + test

The verify table in [`../CLAUDE.md`](../CLAUDE.md) is the source of truth for every command; this subtree adds one fix. `swift test` fails on `import XCTest` with only Command Line Tools installed, so run `sudo xcode-select -s /Applications/Xcode.app` first, or write the tests anyway and let CI run them. Swift coverage is `../scripts/coverage.sh swift`.

## Patterns to match

- **Strict concurrency is on for this target too.** A new `Sendable` warning is a real cross-thread finding; fix it, don't silence it. Two documented `@unchecked Sendable` exist; don't add a third. → [gotchas](docs/gotchas.md#strict-concurrency-is-on-for-this-target) (CONC4)
- **Pure logic on its own type with explicit inputs.** Lift non-trivial branching into a `decide(at:…) -> Action` on its own struct. "It is only presentation" is a reason to extract, not to skip. Repoint the caller: left beside the original it is two copies, one tested. → [gotchas](docs/gotchas.md#pure-logic-on-its-own-type-with-explicit-inputs) (T3, ARCH6)
- **`MeetingSessionController` talks to `SessionHost`, not `Coordinator`.** A new subsystem goes on `SessionHost` and `FakeSessionHost`; a global read has to come through the host. → [gotchas](docs/gotchas.md#meetingsessioncontroller-talks-to-sessionhost-not-coordinator)
- **Fully-qualified type name in stored-property initializers.** `Self.foo` fails on Swift 5.9+; write `StatusBarController.foo`. → [gotchas](docs/gotchas.md#fully-qualified-type-name-in-stored-property-initializers)
- **Combine subscriptions filter to value changes.** `removeDuplicates()` + `dropFirst()` before triggering rebuilds. → [gotchas](docs/gotchas.md#combine-subscriptions-filter-to-value-changes)
- **`ObservableObject` + `@Published` debounce writes.** `ConfigStore.scheduleSave` is the template: 500 ms timer gated on `isInitialized`. → [gotchas](docs/gotchas.md#observableobject-and-published-debounce-writes)
- **Swap the audio engine only through `replaceEngine(reason:)`.** A notification observer registered with `object: engine` is bound to that instance, so a bare `engine = AVAudioEngine()` silently deafens device-change recovery for the rest of the recording. → [gotchas](docs/gotchas.md#a-fix-that-is-correct-at-the-moment-it-runs-and-wrong-immediately-after) (REC16)
- **A repeat scheduled off the main queue needs a `DispatchSourceTimer`.** `Timer.scheduledTimer` attaches to `RunLoop.current` and fires exactly once from a GCD worker. And when a component only works if somebody calls it, fence the *calling*: END9 shipped 28 green tests over a watcher `Coordinator.start()` never started, and END11 the same shape one seam over, an explicit start handing a Leave button to a nil adapter. A silent `?.` on a wiring seam is how both hid. → [gotchas](docs/gotchas.md#a-feature-can-ship-green-documented-and-never-once-run) (END9, END10)
- **TOML round-trip preserves unknown keys.** Read into `TOMLTable`, mutate only what the UI models. New tables need `ensureTable("foo")`; the glossary preserves per *key*, not per table. → [gotchas](docs/gotchas.md#toml-round-trip-preserves-unknown-keys) (FEAT11, UX44)

## Don't

- Don't call Anthropic / Notion APIs from the daemon. Outbound HTTP belongs in the pipeline. → [gotchas](docs/gotchas.md#no-outbound-http-from-the-daemon)
- Don't `bootout` the resident `com.meetingpipe.daemon` agent, and don't add a second mechanism for login-start. `LaunchAtLoginService` is the one owner, and it owns relaunch-after-quit too. Editing `scripts/lib/login-agent.sh` means re-running `sh scripts/test-login-agent-guard.sh`. → [gotchas](docs/gotchas.md#launch-at-login-has-one-owner) (UX42, UX55)
- Don't run a `Process` round-trip on main because the control around it looks cheap, and don't cache a machine reading for a view's lifetime. Every `launchctl` call is watchdogged and off-main; the pane re-reads on `.onAppear`, never per render. → [gotchas](docs/gotchas.md#a-preferences-control-that-shells-out-is-on-the-freeze-list-too) (UX67)
- Don't add startup work to `App.main()` above `SingleInstanceGuard.standDownIfPeerIsRunning()`. Its exit status must stay `EXIT_SUCCESS`, and never read this process's identity from `NSRunningApplication.current` there - before `NSApplication` it is a placeholder with pid -1. → [gotchas](docs/gotchas.md#startup-work-and-the-single-instance-guard) (UX54)
- Don't add a key to `MeetingMetaSidecar.build` without also updating `mp.workflow.apply_overrides`. One contract, two sides. → [gotchas](docs/gotchas.md#the-sidecar-is-a-single-swift-to-python-contract)
- Don't read a per-sink sidecar (`<stem>.notion.json`) to learn whether a run published; read `<stem>.publish.json` via `PublishResult.resolveState`. Changing the Python writer means regenerating the CI4 fixtures. → [gotchas](docs/gotchas.md#publish-state-comes-from-publishjson) (PIPE1, PIPE14)
- Don't spawn `mp summarize` / `mp publish` for an existing meeting outside the pipeline lane; enqueue a `.libraryRun` job. Inside the lane, the regenerate chain calls `performRepublish`, not `republishMeeting`. → [gotchas](docs/gotchas.md#re-runs-go-through-the-pipeline-lane) (PIPE11)
- Don't report work this app stopped as a failure. Ask `PipelineLauncher.isCancellation(err)` first. A cancelled job still completes as a failure and still writes a marker; the cancel flag is per run, never a bool on the launcher. → [gotchas](docs/gotchas.md#a-subprocess-this-app-killed-is-not-a-failure) (UX50, UX69)
- Don't log or write files from inside an audio render callback. Real-time threads; blocking work glitches the recording. → [gotchas](docs/gotchas.md#nothing-blocking-inside-an-audio-render-callback)
- Don't merge the two capture channels without an explicit length policy, and don't let a byte count stand in for "the merge worked". `RecordingPostProcessor.mergeLengths` is the policy; a late-starting channel carries the END of the meeting, so delay it, never zero-anchor it. → [gotchas](docs/gotchas.md#the-two-capture-channels-need-an-explicit-length-policy) (REC9)
- Don't re-open a capture file to resume writing it - `AVAudioFile(forWriting:)` truncates. Keep the handle and pad the gap. And don't leave a teardown path unbounded because a sibling path is bounded. → [gotchas](docs/gotchas.md#never-re-open-a-capture-file-to-resume-writing) (REC10, REC11)
- Don't call `AVAudioEngine` synchronously and unbounded from anywhere (`EngineTeardown`, `boundedEngineStart` and `MicLevelMonitor.startBounded` are the sanctioned shapes), and don't register a notification observer with a non-nil `queue:`, which makes the **poster** wait. `addMainQueueObserver` is the one registration. → [gotchas](docs/gotchas.md#a-notification-observer-with-a-queue-makes-the-poster-wait) (REC13). The SCStream start is `boundedSystemCaptureStart` only, and an abandoned attempt discards what it later produces (`SystemCaptureStartAttempt`); a liveness gate counts from the attempt, never from zero. → [gotchas](docs/gotchas.md#a-start-that-never-returns-is-invisible-to-every-fence-built-for-a-death) (REC17)
- Don't hand a closure that blocks its thread to `runWithTimeout` (or any `Task` whose deadline matters): the deadline shares the cooperative pool, one thread per core, and starves once wedges hold it. Blocking work uses `runBlockingWithTimeout` or `runBoundedSync`. → [gotchas](docs/gotchas.md#a-bound-built-from-tasks-is-only-as-good-as-the-core-count) (CI8)
- Don't hand a format to `installTap` outside `GuardedTapInstall`, and don't call its ObjC `@try` barrier from anywhere else; `installTap` *raises* where `start()` throws, and an uncaught raise aborts the process. A caught raise condemns that engine: replace it and retry at most once on the replacement, never on the condemned one. Don't read `isRunning` as "the engine is up" either. → [gotchas](docs/gotchas.md#installtap-raises-where-start-throws) (REC12)
- Don't let a path that gives up leave the timer that called it armed, and don't trust a comment about what stops a watchdog. Every terminal return from `recoverCapture` stops the engine, and REC8 made a stopped engine the tap watchdog's strongest re-arm trigger, so a recovery that could not succeed spun at 1 Hz for the rest of the meeting. Bound it; a latch on the first failure gives up recoveries that would have worked. → [gotchas](docs/gotchas.md#a-terminal-failure-has-to-stand-its-own-retry-down) (REC15)
- Don't end a hold on a wall clock alone. `CallTeardownOracle`'s cap now yields to a live cross-class reading (`LiveCallSignal`, tri-state: an unresolved probe is `.unknown` and never vetoes), and the drift WARN belongs to the no-evidence cap only. → [gotchas](docs/gotchas.md#a-wall-clock-is-not-evidence-either) (END13)
- Don't let a lone end beat a live signal. `PromotionEngine` tracks each kind's last reading, and a live `processAudioIsRunningInput` vetoes any `yieldsToLiveVeto` lead (logged `lifecycle`/`end_vetoed`); only a vetoed end younger than the debounce corroborates the mic release. → [gotchas](docs/gotchas.md#a-signal-allowed-to-end-a-meeting-alone-must-yield-to-one-saying-the-call-is-up) (END14)
- Don't accept a second read of the same oracle as corroboration, and don't let a "verify" step bypass the guard that would have refused. `rescueProvisionalEnd`'s empty AX walk 120 ms after the signal's own was one sample, not two, and `confirmProvisionalEnd` skipped `tick()`'s `requiresCorroboration` check and then wrote its own walk into `confirmedBy`. Ask a different oracle (`CallTeardownOracle`), and degrade toward the old behaviour when it is unavailable. → [gotchas](docs/gotchas.md#a-signal-cannot-corroborate-itself) (END9)
- Don't take Teams' mute state off the newest file in its log directory, don't believe the timezone that file prints (UTC with a local offset suffixed), and don't add a third app-mute producer without a source tag. Don't read that file's mtime as an activity clock either: it is a flush clock that sits at the previous call boundary through a quiet call. → [gotchas](docs/gotchas.md#teams-mute-state-and-how-to-read-its-log) (MIC8) + [flush clock](docs/gotchas.md#an-oracle-that-cannot-see-is-not-evidence) (END12)
- Don't `print(...)` for event-stream data. Use `Log.event(category:action:attributes:)`. A new category goes in the `CONVENTIONS.md` table in the same commit, snake_case, fenced by `scripts/truth_fences.py`. → [gotchas](docs/gotchas.md#event-stream-data-goes-through-logevent) (CI5)
- Don't hardcode a config default at its read site when more than one reader needs it. `ConfigDefaults` is the single home. → [gotchas](docs/gotchas.md#config-defaults-live-in-configdefaults) (ARCH5)
- Don't put a parenthetical promise about the network in a control's copy without deriving it from the routing. `DigestNarration` is the digest's owner. → [gotchas](docs/gotchas.md#network-promises-in-copy-are-derived-from-the-routing) (UX63)
- Don't spell a summarization backend's display name at its render site. `SummarizationEngine` is the one home, in three registers. A new backend adds one entry there and one `WorkflowBackend` case. → [gotchas](docs/gotchas.md#backend-display-names-live-in-summarizationengine) (UX31)
- Don't describe a privacy clamp in copy written beside it rather than derived from it. Every string builds from `RegulatedMode.effectiveBackend`, and the copy is gated on whether the clamp actually moves anything. → [gotchas](docs/gotchas.md#regulated-mode-copy-is-derived-from-the-clamp) (UX60)
- Don't spell a publish sink's name at its render site, and don't infer the destination from anything but `<stem>.publish.json`. `page_url` says what to open, not who wrote it. A notification action's title is baked into its category at registration. → [gotchas](docs/gotchas.md#publish-sink-names-live-in-publishlanding) (UX49)
- Don't treat a test that two write paths agree as a test that they conflict. `TranscriptOverlayCarry.carry` takes the meeting's resolved glossary terms and counts a contradicting correction apart from `carriedCorrections`; matching is `Clarify.containsTerm`, never a looser rule. → [gotchas](docs/gotchas.md#a-no-op-test-is-not-a-conflict-test) (UX66)
- Don't read a transcript row's speaker off `segment.speakerID`, and don't let one row answer "who is this line" twice. `MeetingCast.rowSpeaker(for:overlay:voiceprintLabels:)` is the one read; `MeetingCast.colorIndex(for:in:)` is the only way to a speaker hue. → [gotchas](docs/gotchas.md#one-row-one-speaker-identity) (UX57, UX58, UX59)
- Don't read one transcript row holding two voices as a diarization *split* failure; `SegmentBuilder.coalesce` merges same-speaker spans, so measure the diarizer's own spans first. The 2:01 case has a boundary already. → [gotchas](docs/gotchas.md#a-transcript-row-is-not-the-diarizers-unit) (DIAR2, DIAR4)
- Don't add a config key to `Config.swift` / `ConfigStore.swift` without a consumer and a line in `config.example.toml`. CI5 fails on a dead knob. → [gotchas](docs/gotchas.md#a-config-key-needs-a-consumer)
- Don't add a field to `<stem>.summary.json` on the Python side without modeling it in Swift's `MeetingSummary` - an unmodeled field is deleted, not preserved. And `<stem>.summary.json`'s mtime never means "generated then"; read `<stem>.run.json`'s `ts`. → [gotchas](docs/gotchas.md#fields-in-summaryjson-must-be-modeled-in-swift) (FEAT10, UX41)
- Don't let a window that holds user-authored text write a record about a file it read once and never re-checked. Re-read and compare identity at save time, and say what moved. → [gotchas](docs/gotchas.md#a-window-holding-user-text-must-re-check-what-it-read) (UX65)
- Don't keep a running job's state in a view the navigator rebuilds. Run state lives on `LibraryRootView` as a `@StateObject`. An unstructured `Task {}` is NOT cancelled when its view dies. → [gotchas](docs/gotchas.md#run-state-must-outlive-the-view-that-started-it) (UX37)
- Don't finish an operation that rewrote a meeting's files without publishing `MeetingStore.revision`, and don't grow a second signal beside it. Publishing is almost never the problem; the break is a pane with `.task(id: meeting.stem)` or `.onAppear` over a disk read. → [gotchas](docs/gotchas.md#finish-an-operation-by-publishing-meetingstorerevision) (UX52, UX53)
- Don't keep state a step must not lose in a view the navigator rebuilds, and don't treat `WorkflowStore.delete` as guaranteed - it returns `false` for the default. `WorkflowDeletion.run` is the one delete flow; an editor saves through `update`, never `upsert`. → [gotchas](docs/gotchas.md#step-state-must-outlive-a-navigator-rebuild) (WF9, UX30)
- Don't render engine prose with `Text(_: String)` or write a second markdown parser (`SummaryMarkdown.inline` is the one rule, inline-only, and `.textSelection(.enabled)` moves with it), and don't fill a dead detail column with a sentence restating the pane beside it (`LibraryScope.ownsTheWholeCentreColumn`, exhaustive). → [gotchas](docs/gotchas.md#one-markdown-rule-and-a-placeholder-is-not-content) (UX71, UX48)
- Don't pile inline styles into a SwiftUI view, and don't declare a shared-looking primitive `private`. New primitives go in `Preferences/PreferencesControls.swift` or `Design/MPButtonStyle.swift`; a real second caller is the trigger to promote. → [gotchas](docs/gotchas.md#shared-primitives-are-the-design-system-and-are-not-private) (UX30, UX51)
- Don't make a scroll-to-top anchor a child of the container carrying the top padding, and never compensate numerically. A source fence over SwiftUI nesting must be run against the bug first: text order alone passes on it. → [gotchas](docs/gotchas.md#a-scroll-anchor-belongs-outside-the-padding-and-ordering-cannot-fence-it) (UX68)
- Don't frame-size a scroll view's Auto Layout document (constraint-host it: TAMIC false, width pinned to `scroll.contentView`), and don't anchor a `CALayer` mask on a scrolling view at `origin: .zero` (take `clip.bounds` whole). → [gotchas](docs/gotchas.md#never-frame-size-a-scroll-views-auto-layout-document) + [mask](docs/gotchas.md#never-anchor-a-calayer-mask-at-origin-zero) (UX34, UX47)
- Don't answer "the window grew past the screen" with another `ScrollView`. The Library window keeps `host.sizingOptions = []` so no rail's content can size it; measure that with `intrinsicContentSize`, never `preferredContentSize`. → [gotchas](docs/gotchas.md#a-window-that-follows-its-content-is-not-fixed-by-adding-a-scroller) (UX70)
- Don't put a bare `Rectangle` (or any `Shape`) as a stack sibling when you want the stack sized to its content. Draw an underline as an `.overlay(alignment: .bottom)`. → [gotchas](docs/gotchas.md#shapes-are-greedy-in-both-axes) (UX36)
- Don't let a `SettingsRow`'s control column fight its label column for width, and don't set a window's minimum below the floor its SwiftUI root declares - use `contentMinSize`, not `minSize`. → [gotchas](docs/gotchas.md#settingsrow-column-widths-and-window-minimums) (UX43)
- Don't offer a picker option whose setter drops it. Either make it a real target or offer it only as a readout. → [gotchas](docs/gotchas.md#never-offer-a-picker-option-whose-setter-drops-it) (UX43, DIAR3)
- Don't pin a contrast ratio for a colour the repo doesn't own. Pin our hex tokens; floor anything built on an AppKit system colour, since its RGB moves between macOS releases. → [gotchas](docs/gotchas.md#never-pin-a-contrast-ratio-for-a-colour-the-repo-does-not-own) (UX59)
- Don't let a capture script emit a verdict it never computed. `window_titles.json`'s `expected` takes `unknown`, which the fixture suite reports instead of asserting, and a `reject` on a real captured title is a DET finding, not a red build. → [gotchas](docs/gotchas.md#a-capture-tool-must-not-emit-a-verdict-it-never-computed) (HYG6, VALOWN1)
- Don't put a detail pane's header on one of its tabs' content measures, don't centre a measured column in an uncapped one (cap, then left-align; a footer gets the width of the thing it serves), and don't cap content at the narrowest allowed window's width: derive a ceiling from what the content reads at, let the frame handle the floor. → [header](docs/gotchas.md#the-detail-header-is-chrome-not-content-measure) + [ceiling](docs/gotchas.md#derive-a-content-ceiling-not-a-floor) (UX36, UX33)
- Don't front, activate, or count a Dock-participating window from its own `show()` (`WindowActivationManager` owns the sequence and counts by identity, since `isVisible` is false while miniaturized), and don't fix a missing command-key shortcut with a hidden control: `MainMenu.swift` is the one place, every item on a nil target. → [activation](docs/gotchas.md#window-activation-has-one-owner) + [menu](docs/gotchas.md#command-key-shortcuts-need-a-main-menu) (UX39, UX56, UX48)
- Don't assume the reading surfaces have a right-click Copy to fall back on. There is no `NSTextView` in this app outside editing sheets. A real mouse selection does engage a working Copy; what is unmeasured is reading that selection programmatically. → [gotchas](docs/gotchas.md#the-reading-surfaces-have-no-nstextview) (UX48, FEAT13)
- Don't put a document on the pasteboard in one flavor, and don't render a share from `<stem>.json`. `RichTextShare.write` sets `.rtf`, `.html` and `.string` on one item, board as a parameter; `MeetingShare` renders what the reader sees, and the transcript half skips the markdown pass. → [gotchas](docs/gotchas.md#a-share-writes-three-flavors-and-renders-what-the-reader-sees) (FEAT16)
- Don't rename or remove a control the tutorial rings without updating the tour in the same commit. Every step is a `TutorialAnchor` case naming the file that attaches it and the file that spells its label, and the fences fail the suite when either stops holding. → [gotchas](docs/gotchas.md#a-tour-is-a-set-of-claims-about-controls) (FEAT15)
- Don't pick a sidecar by excluding the ones you know about. A deny-list of suffixes rots against the on-disk inventory and the reader silently takes whatever `readdir` hands back first; match the name you want. → [gotchas](docs/gotchas.md#a-deny-list-of-sidecars-rots-against-the-inventory) (CI6)
- Don't reference another file's types from `Automation/MeetingPipeAppIntents.swift`. `install.sh` compiles it standalone; the breakage is silent (`swift build` still passes, the Shortcuts actions vanish). → [gotchas](docs/gotchas.md#app-intents-compile-standalone)
- Don't try to make the native App Intents run on an ad-hoc-signed build, and don't re-derive why they don't. Six causes were excluded by measurement; the remaining one is code signing. → [gotchas](docs/gotchas.md#app-intents-are-discoverable-but-not-invocable)
- Don't put a repo path in `docs/GUIDE.md` outside a `<!-- repo-only -->` block; it renders in a window to someone with no checkout. `GuideDocument.canFollow` is an allowlist and flattens the rest. → [gotchas](docs/gotchas.md#a-document-rendered-in-a-window-has-a-second-reader) (DOC13)
